# 打法手册 PLAYBOOK（竞价雷达 + 盘后复盘 使用说明）

> 本手册是 `quant/radar.py`（早盘 9:27 竞价简报）和 `quant/review.py`（15:05 盘后复盘）的规则说明书。
> **所有输出均为量化辅助信号，不构成投资建议；盈亏自负，纪律第一。**

## 二、大盘环境分（radar.py 第一节）

```
环境分 = 加权平均(上证竞价, 创业板竞价, A50期指, 纳指期货, 昨涨停溢价, 市场宽度)
  每项先归一到 0~1（如 ±2% 涨跌幅映射满档），缺失项自动剔除不拖分。
  ≥70 → 强，仓位系数 ×1.1（可上 7 成仓）
  ≤35 → 弱，仓位系数 ×0.7（≤3 成仓，只做弱转强）
  其余 → 中（试错仓）
```

**用法**：环境分决定今天"打不打、打多大"，先看分再选股。分数是漏斗的第一层。

## 三、情绪周期五阶段（review.py 第四节）

```
冰点期：涨停≤25 且 昨涨停溢价 < -2%  → 空仓/首板试错，等跌停消失
退潮期：涨停≤35 且 炸板率 ≥ 40%    → ≤3成仓，只做低位新题材首板
震荡期：其余情况                    → 半仓试错，聚焦 1-2 个主流板块
发酵期：昨涨停溢价 > 2% 且 涨停 ≥ 50 → 进攻，主做中军+卡位二板，6-7成
高潮期：涨停 ≥ 80 且 最高板 ≥ 6 且 炸板率 ≤ 20% → 持龙头，不追跟风
```

**昨日涨停溢价**是全场最情绪的单一指标：溢价 >2% 接力资金愿意付钱；溢价 <-2% 昨日打板的人集体亏钱，次日别接高位板。

## 四、竞价关注池综合分（radar.py 第五节）

```
综合分 = 环境系数 × 100 × ( 0.30×竞价形态 + 0.20×竞价换手 + 0.20×竞价金额
                            + 0.15×板块协同 + 0.15×身位 )

竞价形态 gap_score(g)：高开 2~5% = 1.0（最优）
  低开≤-3% → 0.05；平开 → 0.3；0~2% 线性升；5~7% → 0.8；7~9% → 0.5；>9%（一字）→ 0.25
竞价换手 vol_score：竞价成交额/流通市值，≥0.5% 满分
竞价金额 money_score：≥1亿满分 / ≥3000万 0.7 / ≥1000万 0.4（"大单"口径的竞价版）
身位 position_score：昨日涨停且今高开2-6% = 弱转强 0.7+0.08×连板数；高开>5% 减 0.2（兑现风险）
板块协同 board_score：所属板块进入竞价热度榜，或同板块 ≥5 家高开≥2%
```

**过滤器**：竞价涨幅 ≥1%、竞价金额 ≥800万、流通市值 >20亿（滤壳票）。

### 打法速查（简报"打法"列的展开）

| 形态 | 条件 | 操作 | 止损 |
|---|---|---|---|
| 弱转强 | 昨 N 板 + 今高开 2-6% + 竞价≥3000万 | 竞价末/开盘半路 | 破分时均线 |
| 高开放量 | 高开 2-6% + 竞价≥3000万 | 回踩不破竞价价低吸，追高≤3% | 破竞价价 |
| 平开放量 | 平开 + 竞价≥3000万 | 等开盘第一波分时确认，不抢跑 | 破开盘价 |
| 超高开 | >9% 一字 | 竞价难成交，看封单决定是否排板 | 炸板即走 |
| 低开 | <0% | 除非急杀放量承接，否则观望 | — |

### 开盘后 5 分钟确认信号（9:30-9:35 逐条核对）

1. 第一分钟量比 >3 且股价 ≥ 竞价价 → 信号有效可加
2. 板块内 ≥3 家同步上攻（板块共振）→ 可信度倍增
3. 大盘 9:31 翻绿 / 关注票炸板 → 无条件放弃或减仓

## 五、跷跷板轮动模型（radar.py 第四节）

A 股常见对立组（一涨一跌）：

| 对立组 | 风格 A | 风格 B |
|---|---|---|
| 大小盘 | 上证50（银行/煤炭/红利） | 中证1000（小盘题材/连板） |
| 价值成长 | 沪深300（白马/价值） | 创业板指（科技/成长） |

```
倾向值 = 风格A近5日涨幅 − 风格B近5日涨幅
  倾向值 > 0 → A 侧占优，关注权重/红利方向
  倾向值 < 0 → B 侧占优，关注小盘题材、连板接力
确认信号（9:27 简报第一节指数行）：两侧指数竞价涨跌幅方向相反 = 跷跷板当日继续；
同向高开 = 普涨日，可两边都做但仓位平分。
```

**轮动切换的领先信号**：昨日涨停溢价由正转负 + 小盘指数弱于大盘指数 → 题材退潮，切权重防守；反之溢价回升 + 中证1000 强于上证50 → 切小盘进攻。

## 六、消息面使用规则（radar.py 第二节）

- 电报按关键词打标：🔴利好（中标/预增/回购/政策/降息…）、⚠️利空（减持/立案/关税…）
- **只有满足以下之一才值得为消息动手**：① 涉及简报关注池里的票；② 涉及竞价热度 Top3 板块；③ 政策级别（国常会/部委/美联储）
- 隔夜外围影响权重：A50 期指 > 纳指 > 日韩开盘 > 恒生。A50 高开 >1% 时勿逆势做空权重。
